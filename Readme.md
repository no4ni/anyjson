# anyjson

**Локальный JSON-исполнитель и веб-интерфейс для подключения LLM (DeepSeek, Qwen, GPT, локальных моделей через llama.cpp) к инструментам операционной системы, медиа-обработке, 3D-генерации и работе с файлами.**

Модель взаимодействует с системой через структурированные JSON-команды (в консольном REPL или через встроенный Web UI с нативным Tools API).

> ⚠️ **Отказ от ответственности (используйте на свой страх и риск):**  
> `anyjson` предоставляет модели прямой доступ к файловой системе, терминалу и сети в рамках заданных ограничений. Если вы вручную выполните команду, которая удалит ваши файлы или отправит наружу пароли и ключи — ответственность несёте вы. Если это сделает подключённый ИИ-агент — ответственность несёт тот, кто запустил агента.

## Возможности

- **Файлы и код:** безопасное чтение с пагинацией по КБ, AST-поиск и замена функций, точечные патчи с предпросмотром diff и автобэкапами, поиск по содержимому, работа с архивами (`zip`/`tar`).
- **Графика и Stable Diffusion:** генерация и редактирование изображений через локальный Forge API (ControlNet, апскейл 33 методами, удаление фона, расширение холста, удаление текста через DBNet + LaMa).
- **Видео, аудио и анимация:** нарезка, склейка, наложение звука, автосубтитры, морфинг кадров (SIFT + FaceMesh + IDW), Ken Burns, озвучка через Piper TTS, рендер и текстурирование `.lotty` / SVG.
- **3D-моделирование:** генерация low-poly `.glb` моделей (Y-up для Blender) и изометрических превью из трёх ортогональных проекций.
- **Сеть и автономность:** веб-запросы и поиск (в том числе через Tor `socks5h://` с ротацией цепочек), P2P-взаимодействие агентов.
- **Локальное сжатие контекста:** встроенный пайплайн на базе `rut5-squeeze-fp16` (веса доступны на Hugging Face: `MACreative/rut5-squeeze-fp16`).

## Быстрый старт

### 1. Консольный режим (REPL)

    py anyjson.py Ассистент

При первом запуске создаётся рабочая директория профиля `profiles/<Имя>/memory/`.

### 2. Веб-интерфейс (с поддержкой llama.cpp Tools API)

    py web_server.py

После запуска интерфейс доступен по адресу: `http://127.0.0.1:8081` (сервер слушает только локальный интерфейс `localhost`).

### 3. Настройка путей и API-ключей
Шаблоны конфигурации находятся в `side/config.example.json` и `side/api_keys.example.json`.
Задать пути к внешним инструментам (`ffmpeg`, `ffprobe`, `piper`, `StableDif`) или ключи API можно прямо командой:

    {"настроить": {}}

## Безопасность

- **Защита подпроцессов (`_safe_subprocess.py`):** запрет запуска внешних `.py` скриптов за пределами рабочей директории.
- **Песочница для Python-команд (`_py_guard.py`):** `sys.addaudithook` блокирует запись/удаление в системных каталогах, `shutil.rmtree` и неразрешённые вызовы `subprocess.Popen`.
- **Фильтрация утечек (`leak_guard` / `mask_secrets`):** автоматическая маскировка токенов, ключей и email-адресов в выводе и блокировка их отправки во внешние сервисы.
- **Hot-reload:** изменения в модулях `_actions/*.py` подхватываются на лету между пакетами команд без перезапуска.

## Установка зависимостей

Минимальный набор для запуска ядра и веб-интерфейса:

    pip install -r requirements.txt

Тяжёлые библиотеки для отдельных инструментов (видео, 3D, распознавание речи, локальные модели) ставить заранее не обязательно. При вызове команды, которой не хватает библиотеки, система сама подскажет готовую команду для установки на лету без выхода в терминал:

    {"установить_пакет": {"имя": "trimesh"}}
