Безопасность:
Subprocess: Запуск .py только внутри BASE_DIR. В системные папки (C:\Windows, C:\Program Files) запись запрещена.
Команда "питон": Запускается через guard. Блокирует os.system, subprocess, eval, exec, сетевые библиотеки и запись в системные директории.
Leak Guard: Блокирует отправку секретов (API-ключи, токены) во внешние сервисы, маскирует их в выводе.
Веб-интерфейс: Сервер слушает только 127.0.0.1:8081.

Важные инструменты:
Stable Diffusion (Forge): Запуск только через run.bat. Прямой запуск webui-user.bat создаст нерабочий venv.
Tor: Используется для тор_запрос и доступа к Moltbook. DNS через socks5h://127.0.0.1:9050.
Сжатие текста: Локальная модель rut5-squeeze. Защищено от потери чисел, путей и нарушения баланса скобок.

Механизм @register и алиасы:
@register — декоратор для регистрации команд. Принимает строку или список имён.
- Все имена добавляются в реестр HANDLERS.
- Первое имя из списка становится каноническим и записывается в PRIMARY_HANDLERS (для подсказок и примеров).
- Примеры:
 @register("пост")              — одно имя: "пост"
 @register(["запуск", "терминал", "шелл"]) — каноническое: "запуск", алиасы: "терминал", "шелл"
- Подхватывается автоматически при запуске anyjson.py.

### Архитектура web_server.py

`web_server.py` — тонкий хостинг-слоё. Основная логика сервера находится в `_core/_server.py`.

**Вход:** `web_server.py` импортирует `_core._server` и вызывает `start()`.

**Дизайн:**
- `web_server.py` — просто запускает сервер
- `_core/_server.py` — вся реальная работа:
  - Трединговый HTTP-сервер на порту 8081
  - Запуск `agent.py` в режиме демона (daemon)
  - Обработка сообщений через stdin/stdout пайп
  - Протокол инструментов (tool calls) для llama.cpp
  - Стерилизация ANSI-кодов для точного сравнения ответов

**Потоковая модель:**
1. HTTP-запрос → HTTP-обработчик
2. Сообщается в agent.py через stdin
3. agent.py обрабатывает, возвращает результат через stdout
4. Обработчик передаёт ответ клиенту

**Ключевые детали:**
- Агент работает в отдельном процессе (`--daemon` flag)
- Система промптов динамически подгружается с agent.py
- Лимит 5 итераций инструментов для избежания бесконечных циклов
- Thread-safe управление процессом агента через `threading.Lock()`
