# Дорожная карта развития anyjson (v0.2.0 → v1.0.0)

Этот документ описывает поэтапный план стабилизации ядра, расширения сетевых возможностей и подготовки `anyjson` к первому стабильному мажорному релизу `v1.0.0`.

---

## Текущий этап: `v0.2.0` — Публичный старт и базовая безопасность

- [x] Очистка репозитория от приватных конфигов, ключей, кэшей и бинарных артефактов.
- [x] Публикация весов модели сжатия контекста на Hugging Face (`MACreative/rut5-squeeze-fp16`).
- [x] Дисклеймер об ответственности оператора и безопасности выполнения команд в `Readme.md`.
- [x] Блокировка прямого чтения `api_keys.json` и усиление фильтра утечек (`tools_leak_guard.py` / `mask_secrets`).
- [x] Гарантированное создание `.bak_*` при точечных заменах (`заменить_текст`) и побайтовый прогресс-бар в `переместить` / `копировать`.

---

## `v0.3.0` — Надёжный поиск и сетевой стек (готово)

- [x] Мульти-поисковик в `веб_поиск` (Bing, DuckDuckGo HTML/Lite, SearXNG, AnySearch, Exa MCP, ddgs) с автоматическим фолбэком при блокировках или таймаутах.
- [x] Поддержка **Ollama Web Search API** (`ollama` через `side/api_keys.json` или `OLLAMA_API_KEY`).
- [x] Умный мастер `{"настроить": {"мастер": true}}` — запрашивает только недостающие пути и ключи, не беспокоя по уже настроенным параметрам.

---

## `v0.4.0` — Единый контракт команд и схема

- [ ] Автогенерация шпаргалки (`командыAnyjson.txt`) и JSON Schema для Tools API из единого реестра `@register`.
- [ ] Унификация алиасов параметров во всех модулях `_actions/*.py` (единые имена: `путь`, `откуда`/`куда`, `найти`/`на_что`, `текст`/`содержание`).

---

## `v0.5.0` — Автотесты и CI

- [ ] Набор базовых автотестов (`pytest`) на парсер пакетов `|||`, песочницу (`_py_guard`, `_safe_subprocess`), `leak_guard` и файловые операции.
- [ ] GitHub Actions workflow для проверки синтаксиса и прогона тестов ядра на каждый push и pull request.

---

## `v0.6.0` — Модульность и расширения

- [ ] Чёткое разделение минимального ядра (`_core` + базовые действия) и опциональных пакетов (медиа/Stable Diffusion, 3D-генерация, скраперы, P2P-агенты).
- [ ] Готовые шаблоны и инструкции по подключению внешних и локальных моделей (`llama.cpp`, DeepSeek, Qwen, OpenAI-совместимый API).

---

## `v0.9.0-rc` — Release Candidate (заморозка API)

- [ ] Заморозка имён базовых команд и форматов ответов.
- [ ] Полный аудит безопасности песочницы и кроссплатформенная проверка (Windows + Linux).
- [ ] Финализация пользовательской документации (quickstart, FAQ, типовые сценарии).

## `v1.0.0` — Стабильный релиз

- [ ] 100% прохождение тестов ядра и чистая установка из коробки по `Readme.md`.
