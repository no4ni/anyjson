## ✅ Сделано сегодня (кроме UNaIVERSE)

### Безопасность и защита
- **Страж `subprocess`** — блокирует запуск чужого `.py`. Разрешено только внутри `BASE_DIR`. Исключение — команда «питон» через `allow_external_py()`.
- **`leak_guard`** — почищен от ложных срабатываний (`key`, `ключ`). Теперь ловит реальные секреты, а не любое слово.
- **Отключена камера** в UNaIVERSE через `no img` в `proc_outputs`.
- **Проведён аудит пакета** `unaiverse` — не лезет в микрофон, клавиатуру, скриншоты, реестр, `.ssh`. Использует `subprocess` только для Docker и локального LLM-шлюза (`127.0.0.1`).
- **Статья про камеру** — написана.

### Русские имена команд
- **Строгая проверка** — любая латиница в имени → блок с подсказкой русского аналога.
- **`_is_latin_name`** + `_russian_aliases` + `_latin_alias_hint` — единая логика.
- **`перезапустить_tor` → `перезапустить_тор`**.
- **17 латинских алиасов** — все имеют русского брата-близнеца.

### Подсказки и справка
- **`wrap_json_hints`** — оборачивает JSON-команды в ```text```.
- **`_extract_params_ast`** — вытягивает параметры из кода функции (без ложных `api_key` из соседних блоков).
- **`_doc_for` фильтрует тавтологию** — не показывает параметры, которые уже названы в тексте ошибки.
- **`_wrap_error`** — при ошибке показывает докстринг, но **не подклеивает** для «недоступно».
- **`_russian_name_hint`** — единая функция, фильтр кириллицы во всех местах.
- **`list_commands`** — 5 случайных команд с честной пометкой «это выборка, не полный список».

### Инфраструктура hot-reload
- **Watcher расширен на `_core/`** — `_utils`, `_color`, `_executor`, `_ps` перезагружаются на лету.
- **`_CORE_PRESERVE`** — сохраняет `_ps_cwd` при reload.
- **Позднее связывание** — `cmd_parser` держит `_executor` через модуль, а не через функцию.
- **`anyjson.py` — обёртка `process_command_input`** через `_cmd_parser.process_command_input`.

### Tor и сеть
- **`new_circuit`** через ControlPort 9051 — ротация exit-нод.
- **Retry в `_moltbook_get_token` и `_moltbook_request`** — при CloudFront 403 и timeout.
- **Tavily через Tor** — если Tor поднят, иначе тихо пропускаем.
- **`_dns_retry`** — 4 попытки с нарастающей задержкой при DNS-сбоях.
- **Tavily через Tor (200), напрямую (403)** — доказано.
- **`_graceful_stop` для Tor** — soft kill → 8 сек → жёсткий.

### Moltbook
- **Эндпоинты исправлены** — `/requests → /request`, `/conversations/{id}/messages → /conversations/{id}`.
- **DM-404 кэшируется** на 15 минут — не дёргаем Tor и API зря.
- **Сообщение** `❌ Личные сообщения сейчас недоступны` — без URL, `@moltbook`, `pip install`.
- **6 докстрингов** DM-команд с ⚠️.

### Cooldown
- **Всё в ОЗУ** — `_MOLTBOOK_STATE`, `_BROADCAST_STATE`. Никаких файлов на диске.
- **Трёхуровневый** — успех / первое предупреждение / спам с увеличением на 5 минут.
- **Показывает 3 случайные команды** с `{"помощь": "..."}`.

### Команды и докстринги
- **`help` принимает `тема`**, `query`, `команда`.
- **`записать_файл`** — алиас к `добавить` (дописать/создать, если нет).
- **`юнайверс_*`** — 10 команд (по факту работают, кроме P2P).
- **`прочитать_функцию` / `заменить_функцию`** — синонимы `функция`, `файл`, автопоиск по `_actions/*.py`.
- **`веб_запрос`** — постраничный вывод, кэш TTL 300 сек, `[кэш]`, навигация.
- **`читать_статью_дзен`** — постранично + ссылка на каталог.
- **`обучить_оракула` / `предсказать_продолжение`** — свой докстринг, формат JSON, поддержка позиционных и именованных признаков.
- **`диагностика`** — поиск команд по имени/докстрингу/параметрам с транслитерацией.
- **`юнайверс_лог`** — хвост лога с фильтром и контекстом.
- **`юнайверс_запрос`** — прямой POST к UNaIVERSE API, показывает count.

## ⏳ Осталось в очереди

### Незначительные улучшения
- **Баннер `Привет, t!`** — `_config.py` печатает при каждом импорте. Можно убрать в `if __name__ == "__main__"`.
- **`shell=True`, `os.system`, `os.popen`** — страж их не покрывает. Если нужна полная защита — добавим.
- **`contextvars` в потоках** — если «питон» станет многопоточным, guard не перенесётся. Пока не актуально.
- **`tools_telemetry` в `_SKIP_RELOAD`** — не обязателен после фикса `asyncio`, но можно поставить страховку.

### Докстринги-заглушки
Ещё остались где-то `Параметры: см. реализацию`:
- `clipboard.py` — `картинка_в_буфер`
- `proxy.py` — `получить_прокси`, `удалить_прокси` (уже поправлено)
- Некоторые команды `web_extra.py` — `новости`, `погода`, `энциклопедия`, `архив`, `паста`

Можно пройтись автоматом через `_extract_params_ast` — но не критично.

### Только «если захочется»
- **Sandboxie / виртуалка** — для запуска чужих AI-пакетов на будущее.
- **Мониторинг CPU демона** — если снова начнёт жрать.
- **Пинок в поддержку UNaIVERSE** — с описанием бага agent-to-agent.
- **Повторная попытка UNaIVERSE** — когда выйдет v0.2.x.
